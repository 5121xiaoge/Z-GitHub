# Z-GitHub

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Generate GitHub file proxy URLs and Git Clone commands for the existing
Cloudflare Workers / Pages proxy.

## Capabilities and Constraints

- Preserve the single-file `_worker.js` deployment.
- Preserve the existing proxy routes and environment variables.
- No framework, package installation, account system, or remote deployment.
- Do not invent transfer speeds, availability, download counts, or service health.
- Recent records are held in page memory only; never store credentials.
- This change is scoped to the embedded homepage and its interactions.

## Brand Commitments

The user approved the local Raycast design reference on 2026-11-24, replacing
the earlier Vercel reference after finding the interface too dense and complex.
Keep enterprise-level quality and a premium finish through graphite surfaces,
fine boundaries and restrained coral accents. Reduce content shown at once
without removing the core workflows or their accessible states.
Preserve the Z-GitHub identity; do not copy Raycast branding or marketing.
Retain the light theme and the existing theme preference and motion behavior.
